# Muhammad Arya Saputra - Portfolio Website

> Aspiring Project Manager & AI Enthusiast. Bridging strategic vision with technical execution.

## 🚀 Overview
Personal portfolio website of Muhammad Arya Saputra, featuring:
- **Interactive Blueprint Design Language**: Clean technical aesthetic with customizable grid lines and Figma inspect overlays.
- **Dynamic Typewriter Subheadline**: Human-like typing cadence with natural pacing, micro-pauses, and instant typo correction.
- **Sticky Unfolding Core Expertise**: Interactive scroll-driven card unfolding showing Project Management, Systems Engineering, and Machine Learning.
- **Selected Works & Full-Viewport Case Studies**: Deep-dive showcases including empirical metrics, technical architecture diagrams, hardware BOM audits, and photo galleries with a pure image lightbox.
- **Minimal Monospace Navbar**: Clean centered monospace navigation with active section indicator and responsive mobile hamburger drawer.

## 🛠️ Tech Stack
- **Frontend Framework**: React 19, Vite
- **Styling**: Vanilla CSS, Design System Tokens, Blueprint Grid
- **Motion & Interactions**: Framer Motion (`motion/react`)
- **Icons & Typography**: Google Fonts (Instrument Sans, Space Mono)

## 📦 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
